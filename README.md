Prism-and-Style is a luxury fashion-forward landing page inspired by iconic eyewear aesthetics like Ray-Ban. The project features a modern, editorial UI layout built with smooth animations, custom serif typography (Young Serif), and an immersive visual hierarchy.

# Tech Stack & Features Used:

HTML5: Clean structural layout and semantic design elements.

CSS3: Custom responsive styling, interactive hover transitions, dynamic element alignment, and animated micro-interactions.

JavaScript (GSAP / Shery.js): Smooth canvas overlays, image distortion effects, and interactive visual feedback.

Google Fonts: Integrated typography for a high-fashion, editorial brand feel.
